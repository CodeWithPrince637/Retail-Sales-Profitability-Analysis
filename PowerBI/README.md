# Power BI Dashboard

This folder contains the interactive Power BI dashboard for Retail Sales and Profitability Analysis.

## Dashboard Pages
1. Sales & Product Analysis
2. Customer Analysis
3. Discount & Shipping Analysis

## Key Features
- Sales, Profit, Orders, Customers, Quantity and Profit Margin KPIs
- Interactive Year and Region slicers
- Product, customer and shipping analysis
- Three dashboard pages with interactive visuals

**File:** Retail Sales Power BI Dashboard (.pbix)
